# Quickstart: Events Selection Validation

1. Seed 3 events (scan or capture) in the Events tab.
2. Tap 2 row checkboxes → counter shows `Selected 2 / 3`.
3. Tap `Select all` → `Selected 3 / 3`; tap `Clear` → `Selected 0 / 3`.
4. Select 1 event → `Delete selected (1)` enabled → confirm → only that event disappears.
5. Make 2 events FAILED (airplane mode sync), select both → `Sync selected (2)` → both requeue and send when online; unselected rows untouched.
6. Resize to 360dp width → all top-bar buttons visible, no horizontal scroll.
7. `Clear processed`, `Clear all`, `Scan notifications` still work.
